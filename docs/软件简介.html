软件简介

修改物品制作时间 制作耗时，服主说了算

方舟生存进化服务端 ArkApi 插件：在 config.json 里按蓝图指定物品、精确改写制作秒数，未指定的物品保持原版，支持热重载。

01 · 软件定位

软件定位

想让水泥 3 秒一团、C4 慢慢搓上十分钟？游戏原版只有全局制作速度倍率这类设置，只能笼统地全服拉快拉慢，做不到「只调某几个物品」。

修改物品制作时间（AdjustCraftingTime）解决的就是这个：一个基于 ArkApi 的 Windows 服务端插件。服主在 config.json 的 List 里按蓝图路径逐物品填写制作秒数（支持小数），玩家制作对应物品 / 图纸时插件即时改写耗时；没列出的物品完全走原版逻辑，零干扰。改配置不用重启，一条 Reload 命令立即生效。

03 · 重点功能

按蓝图改写制作耗时 核心

什么功能：插件 Hook 了游戏的物品制作耗时查询（UPrimalItem.GetTimeToCraftBlueprint）。玩家制作物品（含用图纸制作产物）时，插件拿物品蓝图路径去配置表里查：命中就返回服主填写的秒数，没查到就原样交给游戏计算。

什么作用：实现「按物品」维度的制作时间控制——比如只把水泥调快、只把火箭弹调慢，其他一切不动。配置里写的是最终秒数（支持小数），不是倍率，所见即所得。

给你的好处：没有它，你只能动全局制作倍率，要么全服起飞、要么全员坐牢；有了它，经济类物资可以刻意放慢、繁琐杂物可以一把提速，服务器节奏完全由你拿捏。

03 · 重点功能

配置热重载，免重启调参 核心

什么功能：配置集中在 ArkApi\Plugins\AdjustCraftingTime\config.json 的 List 列表里，一条一个物品（蓝图路径 + 秒数）；控制台 / RCON 执行 AdjustCraftingTime.Reload 立即重读生效。

什么作用：线上调数值不用停服——试运营期间随时改、随时验，玩家在线也无感；写错的条目会被黄色警告跳过，不影响其余条目生效。

给你的好处：没有它，每调一次数值都要重启一次服务器、劝退一波在线玩家；有了它，调整即时生效，你可以按玩家反馈随时微调服务器节奏。

03 · 重点功能

稳定与兼容 特色

什么功能：插件加载时把配置 List 编译成内存查找表，钩子查询走加锁快照——RCON 线程热重载与游戏线程制作查询互不干扰；日志模块自动适配 ArkApi 3.54（GBK）/ 3.55（UTF-8）两种控制台编码，中文输出不乱码。

什么作用：高频制作查询不解析 JSON、不拖慢制作界面；配置重载与制作行为并发安全；各版本服务器控制台日志均可读。

给你的好处：没有它，配置热重载可能与制作查询并发冲突、控制台中文一片乱码；有了它，7×24 挂机稳定运行，出问题看日志就能定位。

03 · 重点功能

轻量部署 特色

什么功能：插件只有一个 DLL，不依赖数据库和额外组件；部署只需把 AdjustCraftingTime.dll、config.json、PluginInfo.json 放进 ArkApi\Plugins\AdjustCraftingTime\ 目录；工程另带一键编译（测试版 / 正式版）与一键多服部署脚本供开发者使用。

什么作用：拿到文件一分钟上线；想临时停用，把 DLL 改名为 AdjustCraftingTime.dll.arkapi 重启服务器即可。

给你的好处：没有它，有些插件要装数据库、配依赖、按版本挑文件；有了它，复制粘贴即完成部署，多服务器也能一条脚本铺完。
